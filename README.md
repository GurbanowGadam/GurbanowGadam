## 🚀 Featured project

### [Kuran Kitaphanasy](https://github.com/GurbanowGadam/kuran-kitaphanasy)
An offline Quran reader in Arabic and Turkmen, built end to end from the source-data pipeline to a release-ready app.

- All 114 surahs and 6,236 verses with Turkmen translation, surah introductions and notes, all bundled in the app
- Optional per-surah audio downloads from 5 reciters, verified with SHA-256 and played offline with verse timing
- On-device trackers (prayer, reading progress, tasbih) with no account, ads or analytics
- Layered architecture (`domain / data / presentation`), a large Flutter + Python test suite, and CI with GitHub Actions
- Content validation tools that check the bundled text against the original sources
